# md-tiny（浏览器扩展）v1.0

一个本地 Markdown 编辑器浏览器扩展：**打开即预览 → 点击编辑 → `Ctrl+S` 保存回原文件**。
纯本地离线运行，不收集任何数据。

- 适用浏览器：Chrome / Edge（Manifest V3）
- 发布包体积：约 **477 KB**（其中 551 KB 是**按需加载**的公式组件，首屏实际约 340 KB）
- 版本：**v1.0**
- 界面语言：简体中文 / English 自动识别，可手动切换
- 全部 **16 项参数**可在设置面板中调整：右键扩展图标 →「选项」，或按 `Ctrl+,`

---

## 功能

### 设置面板

选项页独立成页（`options.html`），**16 项参数**改完即时生效并自动保存，无需「确定」按钮。

| 分组 | 可调项 |
| --- | --- |
| 外观 | 主题（亮色 / 暗色 / 跟随系统）、界面语言、正文字号 13–22、正文行高 1.2–2.2、阅读宽度（不限 / 640–1400）、界面动效开关 |
| 编辑器 | 源码字号、缩进宽度（2 / 4 空格）、拼写检查 |
| 预览 | 代码块复制按钮、数学公式渲染、图片点击放大、自动刷新已打开文件 |
| 文件与存储 | 关闭未保存标签时确认、离开页面前提醒、打开文件夹后展开侧栏 |
| 高级 | 版本、分发形态、设置指纹、存储后端；导出设置 / 导入设置 / 恢复默认 |

**导出 / 导入**复用项目自有的 `MDTN-SIG/1` 格式：

```
MDTN-SET/1
version: 1.0
fingerprint: MDTN-F1 1.0 50 57 5C A8 91 3E 99 C2 V90
---
{ "content.fontSize": 16, ... }
```

导入时会比对头部指纹 —— 内容被改动过会明确提示「不一致」而不是静默接受。
导出也可选择 `MDTN-E1` 口令封装，导入时需提供同一口令。

> 设置写入 `localStorage`（选项页与编辑器页面同源，天然共享）并镜像到 `chrome.storage.sync`，
> 因此换设备登录同一账号后设置会自动跟上。

### 阅读与渲染

- **打开即预览** — 打开 `.md` 直接渲染，无需先点「预览」
- **GFM 完整支持** — 表格、任务列表、删除线、脚注、自动链接
- **代码高亮** — Prism 合并包，覆盖 40+ 种语法（JS / TS / Python / Go / Rust / PHP / SQL / Bash / JSON / YAML / Dockerfile / C / Java / Ruby / PowerShell …）
- **数学公式** — KaTeX，支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 与环境式 `\begin{equation}`
  **命中才加载**：正文里没有公式时，一个字节都不会请求
- **深色 / 亮色主题** — 亮色 / 暗色 / 跟随系统三态；正文、代码高亮、滚动条同步换肤
- **大纲侧栏** — 自动扫描标题，随正文滚动高亮，点击跳转
- **代码块一键复制**、**图片点击放大**（`Esc` 退出）
- **HTML 消毒** — DOMPurify 剥除恶意脚本与事件属性，可放心打开任何来源的文件
- **GitHub 风格样式** — github-markdown-css

### 编辑与保存

- **所见即所得编辑** — 点「编辑」后预览区直接变成可编辑容器，字体 / 间距 / 代码底色全部沿用预览样式；
  **没改动过的块用原文切片回写**，只有真正动过的那一块才重新生成 Markdown
- **源码编辑** — 编辑态可一键切到源码框，随时在「所见即所得 ↔ 源码」之间往返，两种方式共用同一份内容
- **字节保真** — 打开时记下换行风格（CRLF / LF）与 BOM，落盘按记录还原；**一个字符都没改时逐字节回放**，
  不会出现「编辑一次、整份文件行尾全变 LF」
- **保存回原文件** — 按钮或 `Ctrl+S`，UTF-8 纯文本**原样写回**，保存后自动回到预览
- **另存为** — 无写权限或换目标文件时使用
- **未保存离开提醒**
- **Tab / Shift+Tab 缩进**（支持多行选区）
- **全文搜索** — 侧栏搜索框扫描当前文件夹，列出文件名 + 匹配行，点击定位

### 多文件与快捷键

- **多标签** — 顶部标签栏切换，未保存的标签带 `●` 标记
- **文件树** — 「打开文件夹」后左侧列出目录内全部 `.md`，点击即开
- **中英文界面** — 按浏览器语言自动识别，工具栏 `中 / EN` 切换

| 组合键 | 作用 |
| --- | --- |
| `Ctrl+Shift+M` | 唤起编辑器（全局） |
| `Ctrl+S` | 保存并写回原文件 |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+B` | 显示 / 隐藏侧栏（全局命令为 `Ctrl+Shift+B`） |
| `Ctrl+Shift+L` | 切换主题（全局） |
| `Ctrl+,` | 打开设置面板 |
| `Esc` | 关闭图片灯箱 / 关闭设置弹层 |

> 全局快捷键由 Service Worker 接收后经 `chrome.storage` 投递给编辑器页面；
> 页面自身也监听同样的组合键，若快捷键被系统占用可自动兜底，两条路径不会重复触发。

## 安装（Chrome / Edge）

1. 解压 `md-tiny-extension-v1.0.zip`
2. 地址栏打开 `chrome://extensions`（Edge 用 `edge://extensions`）
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」，选择解压出的 `md-tiny-extension` 目录
5. 点工具栏图标，或按 `Ctrl+Shift+M`（macOS：`Cmd+Shift+M`）

> 图标再次点击会激活已打开的编辑器标签页，不会重复开窗。

## 技术说明

- 解析渲染：marked + github-markdown-css
- 代码高亮：Prism 精简合并包（min 组件单文件，含 `markup-templating`）
- 数学公式：KaTeX（含 `contrib/auto-render`），全部本地内置
- 安全：DOMPurify 消毒后渲染
- 保存 / 文件树：File System Access API（Chrome / Edge 支持）
- 搜索：JS 逐文件扫描（缓存已读内容），不引入 ripgrep（约 +10 MB，违背体积目标）
- 界面分层：`editor.js`（内核）→ 触发 `onRender` 钩子 → `ui.js`（装饰层）→ `theme.js` / `i18n.js`
- 配置分层：`settings.js`（SCHEMA + 存储 + 校验，无界面）→ `settings-ui.js`（按 SCHEMA 渲染面板，无写死的设置项）
  - 面板由定义表现场生成，加一个设置只需要改 `SCHEMA` 一处
  - `theme` / `lang` 属于"桥接项"：真实存储仍由 `theme.js` / `i18n.js` 持有（它们必须在首帧前同步落地，防主题闪烁），
    `settings.js` 只提供统一读写入口，避免出现两份值互相打架
- 存储：`localStorage`（同步，首屏缓存 + 扩展页同源共享）+ `chrome.storage.sync`（跨设备）
- 产物自证：`BUILD.SIG` 记录逐文件 SHA256 与内容指纹（`MDTN-SIG/1` 格式，实现见 `sig.js`）
- 不支持的浏览器（Firefox 等）：保存退化为另存新文件，打开正常

### 体积构成

| 部分 | 原始 | 说明 |
| --- | --- | --- |
| KaTeX（js + css + 20 个 woff2） | 551 KB | **按需加载**，不出现公式就不请求 |
| Prism | 67 KB | 代码高亮（`prism.js`） |
| marked | 42 KB | 解析 |
| DOMPurify | 28 KB | 消毒 |
| github-markdown-css | 36 KB | 预览样式（含亮/暗两套变量） |
| prism.css | 4.5 KB | 高亮配色（变量驱动，一份服务两态） |
| 应用代码 | 175 KB | 编辑器内核 / **富文本层 `richedit.js`（19 KB）** / 交互 / 主题 / i18n / 签名 / **设置面板（42 KB）** / 样式 / 选项页 |
| 扩展词条 `_locales` | 1.3 KB | 名称与描述的双语 |
| 图标 | 13 KB | 4 种尺寸 |

## 关于「双击 .md 直接打开」

本扩展**不声明** `file_handlers`，原因有两层：

1. `file_handlers` 是 **ChromeOS 独占**能力（扩展侧 Chrome 120+），Windows / macOS / Linux 上不注册系统关联；
2. Chrome 的清单特性表把它**只授权给 packaged app**。普通扩展一声明，加载时就会挂上安装警告，扩展卡片出现「警告」按钮：

   ```
   'file_handlers' is only allowed for packaged apps, but this is a extension.
   ```

   更早的包带着这条警告（无用功能 + 常驻告警），**v1.0 起已移除该键**。

| 平台 | 扩展的 `file_handlers` | 说明 |
| --- | --- | --- |
| ChromeOS（Chrome 120+） | ⚠️ 声明后可用 | 文件管理器「打开方式」可出现本扩展，但会带上述安装警告 |
| **Windows / macOS / Linux** | ❌ 不生效 | 不注册系统关联，且会带上述安装警告 |

`editor.js` 里的 `launchQueue` 消费逻辑**保留**：PWA 形态、或按需把 `file_handlers` 加回清单的构建可以直接复用（片段见仓库根 [`README.md`](../README.md)）；其余环境下是无害空转。

**想在 Windows 上实现「双击 `.md` 用本编辑器打开」，用本仓库的另一个交付物：[`win/`](../win/)** —— 本地启动器，写入 `HKCU` 文件关联，双击即可，无需管理员、无需装扩展。

在没有系统关联的前提下，桌面端最快的替代方式是：**`Ctrl+Shift+M` 唤起编辑器 → 「打开文件」或「打开文件夹」**（File System Access API 会记住上次授权过的目录）。

## 已知限制

- 全文搜索为 JS 逐文件扫描，超大目录（数千文件）时首次搜索会稍慢
- 文件树递归列出全部子目录，深层大目录首次打开可能耗时
- 预览渲染仅允许安全标签，极少数合法但非标准的 HTML 扩展属性会被消毒剥除
- `breaks: true`：单个换行会渲染为 `<br>`，与严格的 GFM 标准略有差异（保留为更符合笔记书写习惯的设定）
- 公式探测为正则预判，极端写法（如公式里嵌套代码块）可能不触发渲染
- 桌面端不支持系统级 `.md` 文件关联（见上文说明）
- 富文本层只覆盖 marked 会产出的那套标签，文档里**手写的原始 HTML 段与链接定义不参与编辑**（整块原样带走，界面中标灰）
- **混合行尾**（同一份文档 CRLF 与 LF 混杂）在编辑保存后按**多数派统一**；只有「一个字符都没改」时才逐字节回放
- 编辑态里输入 `2 * 3 * 4` 这类**成对符号**，保存后会被 Markdown 当成斜体语法 —— 行内语法靠 DOM 结构表达，是该实现方式的固有代价
- 数学公式在编辑态以 `$…$` 源码呈现（与 Typora 同样的取舍），退出编辑立刻变回渲染结果
